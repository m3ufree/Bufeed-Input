# Input Buffer

Буферизация нажатий для Geometry Dash: если вы нажали кнопку прыжка в воздухе — нажатие сработает автоматически при приземлении (в пределах настраиваемого окна в миллисекундах).

## Требования

- Geometry Dash **2.2091**
- [Geode](https://geode-sdk.org/) **6.0.0+**
- Node IDs **не требуются**

## Установка

1. Скачайте `m3ufree.bufeed-input.geode` из [Releases](https://github.com/m3ufree/Bufeed-Input/releases).
2. Откройте меню модов Geode в игре → **Install from file** → выберите скачанный `.geode`.
3. Перезапустите игру.

## Использование

1. Включите мод в меню модов (настройка **Включить Input Buffer**).
2. Настройте **окно буфера** (мс) — 60 мс по умолчанию, от 0 до 200 мс.
3. Во время игры в правом верхнем углу видно индикатор **BUF:N**, где N — количество нажатий, ожидающих в буфере. Пустой буфер — индикатор невидим.

## Оговорки

- Мод предназначен для практики и casual-прохождений: **не используйте его для рейтинговых прохождений** — задержанные нажатия дают преимущество и могут считаться нечестной игрой.
- Возможны конфликты с модами, вмешивающимися во ввод: **CBF (Click Between Frames), MegaHack**. При нестабильности отключите один из них.
- Буферизация работает только для «наземных» режимов (куб, робот, паук). В летящих режимах нажатия в воздухе работают и без буфера.

## Известные проблемы и решения

| Проблема | Возможная причина | Решение |
|---|---|---|
| Индикатор BUF:N не виден | Мод выключен или буфер пуст (индикатор прозрачен) | Включите мод в меню модов; индикатор появляется только при N > 0 — нажмите в воздухе |
| Буфер не срабатывает | Окно буфера 0 мс или конфликт с CBF/MegaHack | Увеличьте окно буфера (например, 60–100 мс); отключите конфликтующий мод |
| Краш при запуске игры | Устаревшие Geode/GD или повреждённый `.geode` | Обновите Geode до 6.0.0+ и GD до 2.2091; скачайте `.geode` из Releases заново |
